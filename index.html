번역 폰트 변환기 — 개인정보처리방침

최종 업데이트: 2026년

1. 수집하는 정보

본 확장 프로그램은 어떠한 개인 정보도 수집하지 않습니다. 사용자의 활동, 방문 사이트, 검색 기록 등을 외부 서버로 전송하지 않습니다.

2. 로컬 저장 데이터

다음 데이터는 사용자의 브라우저에만 저장되며 외부로 전송되지 않습니다:

  • 사용자가 선택한 폰트 설정 (글꼴, 크기, 행간, 자간 등)
  • 사용자가 직접 업로드한 폰트 파일
  • 폰트 순서 정보

3. 외부 서비스

폰트 적용을 위해 다음 공개 CDN에서 폰트 파일만 로드합니다:

  • Google Fonts (fonts.googleapis.com)
  • jsDelivr (cdn.jsdelivr.net)

4. 데이터 삭제

확장 프로그램을 제거하면 모든 로컬 저장 데이터가 자동으로 삭제됩니다.
